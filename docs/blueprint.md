# **App Name**: ShantiAttend

## Core Features:

- Faculty Login: Secure faculty login to access the dashboard for attendance management.
- Student Login: Student login to view attendance status, class schedules, and faculty messages.
- Offline Data Storage: Locally store attendance data when offline and synchronize when the internet is available.
- Text Labeling for Icons: Utilize text labels to ensure students understand each icons meaning. For those students with a low literacy this offers easier usability.

## Style Guidelines:

- Primary color: Light blue (#89CFF0), reflecting trust and calmness appropriate for an educational setting.
- Background color: Very light blue (#F0F8FF), providing a clean and non-distracting backdrop.
- Accent color: Soft green (#90EE90) to highlight interactive elements, suggesting growth and positivity.
- Font: 'PT Sans', a humanist sans-serif that offers readability and a modern, yet warm feel suitable for all users.
- Use a minimal design with large, centrally located buttons to enhance usability on both tablets and low-end smartphones.
- Incorporate icons alongside text labels on buttons to aid users with low literacy.
